1. Resumen y Objetivos del Proyecto

Definición del reto de ingeniería y programación

El Desafío Central

Los estudiantes deberán diseñar, construir y programar un vehículo terrestre de estructura libre con dos motores impulsados por la placa de expansión Wukong (ELECFREAKS). El robot será teledirigido a distancia sin cables, utilizando una segunda tarjeta micro:bit como mando a distancia que transmite órdenes por radiofrecuencia.

Objetivos Pedagógicos

  • Física y Mecánica: Comprender la tracción diferencial (variación de velocidad entre motores para rotación).
  • Telecomunicación: Programar emisión y recepción de datos codificados mediante bloques de radio.
  • Ingeniería Estructural: Ajustar centro de gravedad, reducir fricción y asegurar rigidez mecánica con bloques tipo LEGO.

3. Principio Físico: Tracción Diferencial

¿Cómo gira un vehículo sin dirección mecánica de servomotor?

Avanzar
Motor Izq (M1): +100%
Motor Der (M2): +100%

Ambas ruedas giran hacia adelante a la misma velocidad.

Giro Izquierda
Motor Izq (M1): -100% (o 0%)
Motor Der (M2): +100%

El motor derecho empuja mientras el izquierdo frena o invierte marcha.

Giro Derecha
Motor Izq (M1): +100%
Motor Der (M2): -100% (o 0%)

El motor izquierdo empuja mientras el derecho frena o invierte marcha.

Detener
Motor Izq (M1): 0%
Motor Der (M2): 0%

Ambos motores se detienen por completo.

4. Secuencia Didáctica por Sesiones

Planificación paso a paso para el desarrollo en el aula

Actividades principales:

  • Presentación del problema real: ¿Cómo se mueven los tanques de oruga o los robots aspiradores?
  • Explicación matemática y física básica del giro por diferencial de velocidad.
  • Diseño en papel (boceto) del chasis libre: colocación de la placa Wukong, rueda loca (punto de apoyo) y motores.
Entregable: Boceto técnico firmado por el equipo. Tiempo: 50 min

Pautas de montaje:

  • Montar los 2 motores de bloque Geekservo de forma simétrica.
  • Asegurar un 3er punto de apoyo (rueda pivotante/loca o deslizador redondeado) para evitar vuelcos.
  • Conectar los motores a los conectores **M1 (Izquierdo)** y **M2 (Derecho)** de la placa Wukong.
  • Comprobar que el interruptor de encendido de la Wukong queda fácilmente accesible.
Entregable: Chasis completo ensamblado e inspeccionado. Tiempo: 50 min

Pasos clave de programación:

  1. Importar la extensión wukong en MakeCode.
  2. Establecer un Grupo de Radio Único (ej. Grupo 7) para evitar que mandos de otros grupos interfieran.
  3. Programar micro:bit Emisor: Enviar números (1=Avanzar, 2=Derecha, 3=Izquierda, 0=Stop) al pulsar botones A, B, A+B o al agitar.
  4. Programar micro:bit Receptor: Escuchar eventos al recibir radio (receivedNumber) y accionar motores M1 y M2.
Entregable: Ambas placas flacheadas y sincronizadas. Tiempo: 50 min

Verificaciones comunes:

  • ¿El coche avanza hacia atrás? Invertir polaridad en el código (-100 en lugar de 100) o dar la vuelta al conector físico del motor.
  • ¿El coche gira en sentido contrario? Intercambiar valores entre los puertos M1 y M2.
  • Ajustar aceleración y balance para evitar que un motor empuje más que el otro.
Entregable: Vehículo perfectamente calibrado operando a control remoto. Tiempo: 50 min

Actividades finales:

  • Recorrido de maniobrabilidad en circuito de conos/obstáculos.
  • Presentación exprés de 2 minutos por equipo: explicando dificultades encontradas y mejoras estructurales relizadas.
  • Cumplimentación de la rúbrica de evaluación y recogida del material.
Entregable: Rúbrica completada y desmontaje ordenado. Tiempo: 50 min

5. Programación MakeCode

Códigos listos para copiar o transcribir a bloques

Placa: micro:bit 1 (Mando Emisor) 
// ==========================================
// CÓDIGO DEL MANDO A DISTANCIA (EMISOR)
// ==========================================

// Al iniciar: Configurar el canal de radio (DEBE SER IGUAL EN EL ROBOT)
radio.setGroup(7)
basic.showIcon(IconNames.Square) // Indicador de listo

// Botón A: Avanzar (Envía 1)
input.onButtonPressed(Button.A, function () {
    radio.sendNumber(1)
    basic.showArrow(ArrowNames.North)
})

// Botón B: Girar a la Derecha (Envía 2)
input.onButtonPressed(Button.B, function () {
    radio.sendNumber(2)
    basic.showArrow(ArrowNames.East)
})

// Botones A+B juntos: Girar a la Izquierda (Envía 3)
input.onButtonPressed(Button.AB, function () {
    radio.sendNumber(3)
    basic.showArrow(ArrowNames.West)
})

// Agitar el mando: Detener el vehículo (Envía 0)
input.onGesture(Gesture.Shake, function () {
    radio.sendNumber(0)
    basic.showIcon(IconNames.No)
})
Botón A Transmite el número 1 (Avanzar)
Botón B Transmite el número 2 (Giro Der)
Botón A+B Transmite el número 3 (Giro Izq)
Agitar (Shake) Transmite el número 0 (Parar)
Placa: micro:bit 2 + Placa Wukong (Receptor)
Importante: Añade primero la extensión Wukong en MakeCode: Busca wukong en el menú Extensiones. 
// ==========================================
// CÓDIGO DEL VEHÍCULO WUKONG (RECEPTOR)
// Requiere Extensión: wukong
// ==========================================

// Al iniciar: Mismo grupo de radio y detener motores
radio.setGroup(7)
wukong.stopAllMotor()
basic.showIcon(IconNames.Happy)

// Al recibir cualquier número por radiofrecuencia:
radio.onReceivedNumber(function (receivedNumber) {
    if (receivedNumber == 1) {
        // ACCIÓN: Avanzar (M1 y M2 al 100% adelante)
        wukong.setMotorSpeed(wukong.MotorList.M1, 100)
        wukong.setMotorSpeed(wukong.MotorList.M2, 100)
        basic.showArrow(ArrowNames.North)

    } else if (receivedNumber == 2) {
        // ACCIÓN: Girar Derecha (M1 avanza, M2 invierte)
        wukong.setMotorSpeed(wukong.MotorList.M1, 100)
        wukong.setMotorSpeed(wukong.MotorList.M2, -100)
        basic.showArrow(ArrowNames.East)

    } else if (receivedNumber == 3) {
        // ACCIÓN: Girar Izquierda (M1 invierte, M2 avanza)
        wukong.setMotorSpeed(wukong.MotorList.M1, -100)
        wukong.setMotorSpeed(wukong.MotorList.M2, 100)
        basic.showArrow(ArrowNames.West)

    } else if (receivedNumber == 0) {
        // ACCIÓN: Detener motores por completo
        wukong.stopAllMotor()
        basic.showIcon(IconNames.Asleep)
    }
})

Amplía el Proyecto (Retos Extra)

Para alumnado avanzado o grupos rápidos

1. Control Acelerómetro (Volante por Inclinación)

En lugar de botones, lee la inclinación del mando (input.rotation(Rotation.Pitch) y Roll) para dirigir el robot como si fuera un volante real.

2. Luces y Sonido Wukong

Enciende los LED Neopixel integrados en la parte inferior de la placa Wukong: color rojo al frenar, parpadeo azul/rojo al girar o claxon al pulsar la pantalla táctil de la micro:bit.

3. Frenado Autónomo Anti-colisión

Conecta un sensor de ultrasonidos en el frontal. Si el vehículo detecta una pared a menos de 10 cm, anula la orden del mando y detiene automáticamente los motores.

Guía de Solución de Errores

Incidencias habituales en el aula

Problema: Interference entre varios grupos

Solución: Asegúrate de que cada pareja/grupo tenga asignado un número de radio diferente en radio.setGroup(N) (por ejemplo, Grupo 1 usa el canal 1, Grupo 2 el 2, etc.).

Problema: El coche gira en círculos al avanzar

Solución: Uno de los motores está montado al revés. Invierte la polaridad en el código enviando -100 a ese motor específico o gira físicamente el conector del cable del motor en la Wukong.

Problema: La micro:bit del coche se reinicia sola

Solución: La batería de la placa Wukong está descargada. Conecta la placa Wukong por cable micro-USB hasta que los LEDs azules de carga de la placa se estabilicen.
